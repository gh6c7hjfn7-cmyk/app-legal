Support — Pack Run

Pack Run has one job: are dogs at this park. Location finds nearby parks. Occupancy is this device (or the same local preview) unless a LAN occupancy API is up. There is no account, no chat, no ads, and no in-app purchases in v1.

How to get help

Use the App Store product page for Pack Run (Report a Problem / contact the developer). That is the intended support channel until a dedicated public email is published here.

Common issues

  • Park list: allow Location When In Use to search nearby OSM dog parks. If location is off, or the map is down, a short fallback list still works.
  • Who’s here: on the App Store / TestFlight build, occupancy is this phone. Copy says “This phone only.” Other phones appear only on a local LAN preview when that API is up. The app does not invent a crowd.
  • Check-in gone: check-ins expire after 90 minutes, or when you tap We’ve left. Deleting the app removes the local dog profile.
  • Privacy: see the Privacy Policy.
