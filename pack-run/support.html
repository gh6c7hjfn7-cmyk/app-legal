Support — Pack Run

Last updated: 2026-08-23T17:12:00.000Z

Pack Run has one job: are dogs at this park. Location finds nearby parks (When In Use). Check-in posts park, pack size, time, and a hashed device id to a live occupancy board for 90 minutes, then the row is erased. GPS, photos, and names stay on this phone. If the occupancy host is down, occupancy is this phone only. There is no account, no chat, no ads, and no in-app purchases in v1.

How to get help

Email nightorders.apps@icloud.com.

Common issues

  • Park list: allow Location When In Use to search nearby OSM dog parks. If location is off, or the map is down, a short fallback list still works.
  • Who’s here: a live occupancy board records park, pack size, time, and a hashed device id. GPS, photos, and names stay on this phone. If the occupancy host is down, copy says “This phone only.” The app does not invent a crowd.
  • Check-in gone: check-ins expire after 90 minutes, or when you tap We’ve left. Deleting the app removes the local dog profile.
  • Privacy: see the Privacy Policy.
