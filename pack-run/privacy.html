Privacy Policy — Pack Run

Effective date: 2026-08-20
App: Pack Run (iOS)
Bundle ID: com.packrun.app
Developer: Independent developer

One function: are dogs at this park.

Location is used only to find nearby dog parks. When you check in, dog name, an optional thumbnail photo, park, pack size, time, and a random device id go to a shared live board so other people using Pack Run can see who is at that park. Rows expire after 90 minutes. No account. No chat. No ads. No analytics SDK. No IAP. No tracking.

App Store privacy label intent: Precise Location and Photos (optional) for App Functionality. User Content (check-in on the live board). Tracking: No.

Short version: You can use Pack Run without an account. Location finds parks. Checking in publishes a short occupancy row so other testers see your dog at that park. Leave, wait 90 minutes, or delete the app to stop showing.

2. On your device

WebView localStorage (pack-run-v1) plus a random device id holds dog name, optional full photo, pack size, and current check-in. Deleting the app or clearing WebView data removes that copy. We cannot restore it.

3. Location (optional)

If you allow Location When In Use, Pack Run reads coordinates to find nearby OpenStreetMap dog parks (Overpass and Photon) and to show distance. Not for ads, tracking, or background following. Deny location and a short list still works. Dog photos are not sent to Overpass.

4. Live occupancy board

When you check in, Pack Run publishes: random device id, park, pack size, dog name, optional thumbnail (not the full camera file), timestamp. Other installs poll the board about every 8 seconds while open to show Who’s here and a connected dog on the opening screen.

The tester board is stored via GitHub (a gist used as occupancy storage). Rows last 90 minutes or until you tap We’ve left. If the board is down, occupancy fails open to this phone. The app does not invent a crowd.

Do not check in with a photo you do not want other testers to see. There is still no Pack Run account.

5. We do not

  • Email / password account
  • Chat
  • Background location
  • Required camera (photo picker is optional)
  • Ads, analytics SDKs, IDFA, or sale of personal information

6. Third parties

  • Apple — App Store, TestFlight, OS
  • Overpass / OpenStreetMap / Photon — park search (coordinates only)
  • GitHub — occupancy board storage for live check-ins
