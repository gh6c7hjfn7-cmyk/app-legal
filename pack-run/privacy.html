Privacy Policy — Pack Run

Effective date: 2026-08-20T00:00:00.000Z
Last updated: 2026-08-20T00:00:00.000Z
App: Pack Run (iOS)
Bundle ID: com.packrun.app
Developer: Independent developer

One function: are dogs at this park.

Location is used only to find nearby dog parks. Check-in (dog name, optional thumbnail, park, pack size, time, random device id) stays on this phone in the App Store / Review binary. A live tester board is used only if that binary was built with board credentials; rows then expire after 90 minutes. If the board is down or not configured, occupancy is this phone only. No account. No chat. No ads. No analytics SDK. No IAP. No tracking.

App Store privacy label intent: Precise Location and Photos (optional) for App Functionality. User Content only if a live board is configured. Tracking: No.

Short version: You can use Pack Run without an account. Location finds parks. Checking in records occupancy on this phone. If a live tester board is configured, other testers can see that row for 90 minutes. Leave, wait 90 minutes, or delete the app to stop showing.

2. On your device

WebView localStorage (pack-run-v1) plus a random device id holds dog name, optional full photo, pack size, and current check-in. Deleting the app or clearing WebView data removes that copy. We cannot restore it.

3. Location (optional)

If you allow Location When In Use, Pack Run reads coordinates to find nearby OpenStreetMap dog parks (Overpass and Photon) and to show distance. Not for ads, tracking, or background following. Deny location and a short list still works. Dog photos are not sent to Overpass.

4. Occupancy (this phone; live board only if configured)

When you check in, Pack Run stores on this phone: random device id, park, pack size, dog name, optional thumbnail (not the full camera file), timestamp.

The App Store / Review binary includes no board token. Occupancy is this phone. The app does not call GitHub for occupancy unless a live tester board was configured at archive time (Internal TestFlight). Those rows last 90 minutes or until you tap We’ve left. If the board is down or not configured, occupancy fails open to this phone. The app does not invent a crowd.

Do not check in with a photo you do not want other testers to see if you are on a live-board build. There is still no Pack Run account.

5. We do not

  • Email / password account
  • Chat
  • Background location
  • Required camera (photo picker is optional)
  • Ads, analytics SDKs, IDFA, or sale of personal information

6. Third parties

  • Apple — App Store, TestFlight, OS
  • Overpass / OpenStreetMap / Photon — park search (coordinates only)
  • GitHub — occupancy board storage only when a live board is configured
