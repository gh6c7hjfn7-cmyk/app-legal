Privacy Policy — Pack Run

Effective date: 2026-08-23T17:12:00.000Z
Last updated: 2026-08-23T17:12:00.000Z
App: Pack Run (iOS)
Bundle ID: com.packrun.app
Developer: Independent developer

One function: are dogs at this park.

Location is used only to find nearby dog parks, and only while the app is in use. When you check in, a live occupancy board records park, pack size, time, and a hashed device id. That row lasts 90 minutes, then it is erased. Still at the park? Check in again. GPS, photos, and dog names stay on this phone — they are not sent on the occupancy wire. If the occupancy host is down, occupancy is this phone only. You can add, change, or delete dogs on this phone. Master delete blanks the pack. OOOPS can put the last erase or last removed dog back. No account. No chat. No ads. No analytics SDK. No IAP. No tracking.

App Store privacy label intent: Precise Location and Photos (optional) for App Functionality. Occupancy check-in is User Content on the live board (park + pack + hashed device). Tracking: No.

Short version: You can use Pack Run without an account. Location finds parks. Checking in posts park, pack size, time, and a hashed device id to the occupancy host for 90 minutes, then the row is erased. GPS, photos, and names stay on this phone. If the host is down, occupancy is this phone only. Leave, wait 90 minutes, master-delete, or delete the app to stop showing.

2. On your device

WebView localStorage (pack-run-v1, pack-run-oops-v1) plus a random device id holds your dogs, which dog is on the board, pack size, current check-in (90 minutes), and the last OOOPS snapshot. Master delete blanks the pack. OOOPS can put that last erase back until you erase again. Deleting the app or clearing WebView data removes that copy. We cannot restore it after that.

3. Location (optional)

If you allow Location When In Use, Pack Run reads coordinates to find nearby OpenStreetMap dog parks (Overpass and Photon) and to show distance. Not for ads, tracking, or background following. Deny location and a short list still works. Dog photos are not sent to Overpass. Location is When In Use only. Pack Run does not request Always location.

4. Occupancy (live board; fail-open this phone)

When you check in, Pack Run stores on this phone: random device id, park, pack size, dog name, optional thumbnail (not the full camera file), timestamp, and GPS used to confirm you are at the park.

The occupancy host is https://pack-run-occupancy.s7jvx9zpbk.workers.dev (Cloudflare Workers). The Review / App Store binary includes that host. There is no GitHub gist board and no gist token. The public occupancy row is park, pack size, time, and a hashed device id — not GPS, not photos, not dog names. Those rows last 90 minutes, then they are erased. Still at the park? Check in again. Leave deletes the row now. If the occupancy host is down, occupancy fails open to this phone. The app does not invent a crowd.

There is still no Pack Run account.
