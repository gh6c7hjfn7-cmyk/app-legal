Privacy Policy — Pack Run

Effective date: 2026-08-19
App: Pack Run (iOS)
Bundle ID: com.packrun.app
Developer: Independent developer

This policy matches the current v1 design: one function — are dogs at this park. Location is used to find nearby dog parks. Occupancy is this device (or the same local preview) unless a LAN occupancy API is up. No account. No tracking. No chat. No ads. No analytics SDK. No in-app purchases.

Short version: Pack Run answers one question: are dogs at this park. Location finds parks. Check-ins live on this phone. Other phones see them only if a local LAN occupancy API is running. We do not require an account. We do not chat. We do not track you.

2. What the app is

Pack Run is a park check-in. You name your dog (optional photo). You see nearby OSM dog parks when location is on. You check in. Status is Quiet / A few / Busy. Check-in expires in 90 minutes. Empty parks say “Be the first dog here.”

It is not a social network with accounts. It is not a tracker. It is not a health or veterinary product.

On iOS the app is packaged with Capacitor: a native shell that shows the UI in an embedded WKWebView. Saves run inside that WebView. Location uses the system When In Use permission.

3. Information stored on your device

Pack Run stores state with WebView localStorage (keys pack-run-v1 and a local device id). This typically includes:

  • Dog name, optional photo, and pack size (1–4)
  • Your current check-in (park, time, pack, name, photo) until it expires or you leave
  • A random device id used only to tell your check-in from another on the same local preview

This stays on your device unless a LAN occupancy API is reachable (section 5). There is no Pack Run cloud account.

Deleting the app, or clearing WebView data for the app, removes that local data. We cannot restore local-only rows from our side.

4. Location (optional)

If you allow Location When In Use, Pack Run reads your current coordinates to:

  • Find nearby OpenStreetMap dog parks via overpass-api.de
  • Show distance, and whether you are close to a park when you check in

Those Overpass requests include latitude and longitude so the feed can return nearby parks. Location is not used for ads, tracking, or background following. The usage string on the system prompt is: Pack Run uses your location to find nearby dog parks and to check you in at the one you’re standing in. It does not track you in the background.

If you deny location, or the park list is down, you can still browse a short fallback list of parks. Occupancy still works as described in section 5.

OpenStreetMap / Overpass operate that API. Their terms apply to the request they receive. We do not send your dog photo or check-in to Overpass.

5. Occupancy (this device unless LAN API is up)

The shipping App Store / TestFlight binary does not talk to a Pack Run cloud. Occupancy is this device. The UI says “This phone only.” when the occupancy request is not available.

A local development / same-Wi-Fi preview can expose GET/POST /api/occupancy on that machine. If that LAN API is up, check-ins on devices hitting that preview (device id, park, pack, dog name, optional capped photo, timestamp) are stored on that local machine for 90 minutes so those devices can see each other. That is a local preview, not an internet multi-user service.

If the LAN API is down or the request times out, occupancy fails open to this phone. The app does not invent a crowd.

6. Information we do not collect (v1)

  • Name, email, or password for an account
  • Chat messages (there is no chat)
  • Background location
  • Contacts, microphone, or camera as a required feature (an optional dog photo may use the photo picker)
  • Advertising or analytics SDKs
  • Advertising Identifier
  • Sale of personal information

We do not use location except as described in section 4.

7. Internet access

The App Store build loads bundled assets from the app package for the UI. Core check-in is intended to work without an account and without a Pack Run server. The app uses the network for:

  • Optional Overpass park-list requests (if location is allowed)
  • Optional LAN occupancy requests when a local preview API is reachable
  • App Store updates and system services outside our control

8. Analytics and crash data

No first-party or third-party analytics product is enabled. Apple may collect standard App Store / OS diagnostics governed by Apple’s policies and your device settings.

9. Children

Pack Run is not directed at children under 13 as a data-collecting social product. v1 has no chat, ads, or accounts. Occupancy on the shipping binary is this device.

10. Retention, security, choices

Local data remains on your device until you delete the app or clear app/WebView data. LAN occupancy rows (if a local API is up) expire after 90 minutes. Developer-held cloud occupancy for v1: none. No method of storage is 100% secure.

  • Use the app without creating an account.
  • Deny location; a short park list still works.
  • Skip the dog photo.
  • Delete the app to remove local data from that installation.
  • Limit optional system analytics / crash sharing in iOS Settings.

11. Changes and contact

We may update this policy when data practices change. Material changes will be reflected in App Store privacy answers as required. If a build ships internet occupancy, accounts, chat, or analytics, this document and the store labels will be updated with that release.

For privacy questions, use the Support page or the App Store product-page support channel. There is no public inbox at a placeholder domain.
