Privacy Policy — Pack Run

Effective date: 2026-08-20T00:00:00.000Z
Last updated: 2026-08-20T00:00:00.000Z
App: Pack Run (iOS)
Bundle ID: com.packrun.app
Developer: Independent developer

One function: are dogs at this park.

Location is used only to find nearby dog parks. Check-in stays on this phone unless a live occupancy board is configured. A live board row lasts 90 minutes, then it is erased. Still at the park? Check in again. GPS, photos, and dog names are not sent on the public occupancy wire. You can add, change, or delete dogs on this phone. Master delete blanks the pack. OOOPS can put the last erase or last removed dog back. No account. No chat. No ads. No analytics SDK. No IAP. No tracking.

App Store privacy label intent: Precise Location and Photos (optional) for App Functionality. User Content only if a live board is configured. Tracking: No.

Short version: You can use Pack Run without an account. Location finds parks. Checking in records occupancy on this phone. If a live board is configured, other people using the app can see that you are at a park for 90 minutes. After 90 minutes the row is erased. Still there? Check in again. Leave, wait 90 minutes, master-delete, or delete the app to stop showing.

2. On your device

WebView localStorage (pack-run-v1, pack-run-oops-v1) plus a random device id holds your dogs, which dog is on the board, pack size, current check-in (90 minutes), and the last OOOPS snapshot. Master delete blanks the pack. OOOPS can put that last erase back until you erase again. Deleting the app or clearing WebView data removes that copy. We cannot restore it after that.

3. Location (optional)

If you allow Location When In Use, Pack Run reads coordinates to find nearby OpenStreetMap dog parks (Overpass and Photon) and to show distance. Not for ads, tracking, or background following. Deny location and a short list still works. Dog photos are not sent to Overpass.

4. Occupancy (this phone; live board only if configured)

When you check in, Pack Run stores on this phone: random device id, park, pack size, dog name, optional thumbnail (not the full camera file), timestamp.

The App Store / Review binary includes no board token until a token-free occupancy host is live. Occupancy is this phone in that binary. If a live occupancy board is configured, the public row is park, pack size, time, and a hashed device id — not GPS, not photos, not dog names. Those rows last 90 minutes, then they are erased. Still at the park? Check in again. Leave deletes the row now. If the board is down or not configured, occupancy fails open to this phone. The app does not invent a crowd.

Do not check in with a photo you do not want other testers to see if you are on a live-board build. There is still no Pack Run account.

  • Required camera (photo picker is optional)
  • Ads, analytics SDKs, IDFA, or sale of personal information
